# Padrões Visuais

Guia de cores, tipografia e componentes do ArtOne.

## 🎨 Paleta de Cores

Veja [padrao-cores.css](padrao-cores.css) para os valores exatos.

### Cores Principais

- **Laranja ArtPetro:** #E25F21 (Pantone 165 C)
- **Laranja Escuro:** #C04A1A (hover/focus)
- **Laranja Claro:** #F5D5C0 (backgrounds)

### Cores Neutras

- **Preto:** #000000
- **Cinza:** #C9C9C9 (Pantone 420)
- **Branco:** #FFFFFF

### Badges

- **Ativo (verde):** #D5F4E6 bg, #27AE60 text
- **Inativo (vermelho):** #FADBD8 bg, #E74C3C text
- **Pendente (amarelo):** #FEF5E7 bg, #F39C12 text

## 📖 Tipografia

- **Font:** Sistema (Arial, Helvetica, sans-serif)
- **Tamanho base:** 14px
- **Heading 1:** 32px, bold
- **Heading 2:** 24px, bold
- **Heading 3:** 18px, bold

## 🧩 Componentes

- **Botões:** Laranja (#E25F21), hover #C04A1A
- **Inputs:** Borda cinza, foco laranja
- **Cards:** Sombra suave, borda opcional
